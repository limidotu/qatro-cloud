# Qatro's cloud workspace

This server runs Linux. Its workspace is `/home/qatro/workspace`.

Memory can contain historical Windows paths. They refer to the user's PC.
Do not assume those files exist on this server.

Use Linux shell commands for local tools. The `pc` tool name now refers to
this cloud workspace. The Windows desktop and GPU remain on the user's PC.

The configured model uses OpenCode's free offer. Free offers can change.
Do not enable a paid provider or add billing details without the user's request.

Keep credentials out of responses, workspace files, logs, and GitHub.

The GitHub controls change this server's power state. They do not prove that
the Discord gateway is healthy. A stopped server cannot receive messages.
